# IronMem 0.4.2

This update replaces bundled SQLite with 3.54.1 to address CVE-2026-119375 (RUSTSEC-2026-0459). SQLite builds of IronMem 0.4.1 use the affected library. Stop IronMem, retain a verified database backup and follow the [upgrade procedure](../installation-and-recovery.md) before replacing the executable. The default storage backend remains SQLite. Optional PostgreSQL uses the same SQLx 0.9.1 driver family. Source builders need Rust 1.94 or newer for these drivers.

The confirmation verifier now requires at least 32 key bytes, matching the issuer. If you configured a shorter confirmation key, replace it with at least 32 cryptographically random bytes and issue fresh confirmations. The attestation and confirmation formats retain their existing version. The default configuration leaves both key files unset.

The lockfile also updates rmcp, rustix, quinn-udp and url for RUSTSEC-2026-0462, RUSTSEC-2026-0486, RUSTSEC-2026-0538 and RUSTSEC-2026-0592. The rmcp advisory concerns its HTTP client. IronMem selects its server transport. A dependency advisory alone does not establish exposure through every IronMem interface.
