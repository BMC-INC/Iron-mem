# IronMem 0.4.1

This release gives the accumulated 0.4.0 improvements a distinct installable version, including project memory diagnostics, verified recovery and installation, governed source recall, and the corrected slug-reuse coding verifier.

The MCP server now reports the same version as the executable. Release archives include the executable, README and Apache-2.0 license; SHA256SUMS covers every archive.

Use an isolated configuration for evaluation. Stop existing IronMem processes and retain a verified database backup before choosing to upgrade a live installation. This release does not automatically replace installed binaries, modify assistant configurations, or enable optional model providers.

Validation includes the existing cross-platform CI, disposable memory save-and-recall with the official MCP Python SDK, and the separately packaged Cursor plugin's transport and installation checks. See [release integration checks](VALIDATION.md) for the exact client and artifact checks. Optional ONNX/GPU backends and every graphical MCP client are not certified by these checks.
